HỆ THỐNG DỊCH VỤ MẠNG DOANH NGHIỆP

Môn học: Hệ Điều Hành Mạng • Nền tảng: Ubuntu Server 24.04 LTS

Trang thông tin nội bộ: web.lab.local (192.168.10.10)

Các Dịch Vụ Mạng Cốt Lõi

  • OpenSSH Server (Port 22): Quản trị dòng lệnh từ xa an toàn
  • DHCP Server (Port 67/UDP): Cấp phát IP tự động (192.168.10.100 - 150)
  • DNS BIND9 (Port 53): Phân giải thuận nghịch miền lab.local
  • Nginx Web Server (Port 80): Cổng thông tin doanh nghiệp nội bộ
  • UFW Firewall: Kiểm soát truy cập đặc quyền tối thiểu (Least Privilege)
